## 四、地支关系

查询命令（支持 1–3 个地支或天干）：

```bash
python scripts/yijing.py relation 子 丑
python scripts/yijing.py relation 申 子 辰
python scripts/yijing.py relation 子
```

| 类别 | 内容 |
|---|---|
| 六合 | 子丑合土、寅亥合木、卯戌合火、辰酉合金、巳申合水、午未合 |
| 六冲 | 子午、丑未、寅申、卯酉、辰戌、巳亥 |
| 三合局 | 申子辰合水、亥卯未合木、寅午戌合火、巳酉丑合金 |
| 三会方 | 寅卯辰会东方木、巳午未会南方火、申酉戌会西方金、亥子丑会北方水 |
| 六害 | 子未、丑午、寅巳、卯辰、申亥、酉戌 |
| 相刑 | 寅巳申无恩之刑、丑戌未恃势之刑、子卯无礼之刑、辰午酉亥自刑 |
| 相破 | 子酉、寅亥、卯午、辰丑、巳申、未戌 |

**易错点**：三合局与三会方都看三个地支，但三合是「生旺墓」三角（如申子辰），三会是相邻三个方位（如寅卯辰）。断强弱时三会方力量大于三合局。

**易错点**：寅亥既是六合又是相破，申亥既相害又相刑——同一组合可落在多个关系上，查询时会全部列出，不可只取其一。

## 五、六十甲子与纳音

六十甲子由十天干与十二地支配对，阳干配阳支、阴干配阴支，共 60 组，第 61 回归甲子。纳音每两组一音，共三十音。

常用：甲子乙丑海中金、丙寅丁卯炉中火、戊辰己巳大林木、庚午辛未路旁土、壬申癸酉剑锋金、甲戌乙亥山头火，余见 `data/ganzhi.json`。

## 六、换算规则

### 年干支

`(公历年 − 4) mod 60`，余数 0 为甲子，1 为乙丑，依次顺推。

**易错点**：年份交界按**立春**还是**农历正月初一**，流派不同。本 Skill 按立春分界，在立春当日可能有一日之差，脚本已提示核对。

### 年上起月（月干）

口诀：甲己之年丙作首，乙庚之岁戊为头，丙辛之岁寻庚起，丁壬壬位顺行流，戊癸之年甲好求。

即正月（寅月）天干由年干决定，之后逐月顺推。

### 日上起时（时干）

口诀：甲己还加甲，乙庚丙作初，丙辛从戊起，丁壬庚子居，戊癸何方发，壬子是真途。

即子时天干由日干决定，之后按时辰顺推。

### 日干支

以锚点日推算：公历 2026-09-22 为己亥日，与其余日期相差天数即为干支进退数。脚本已内置该锚点，**日柱为精确值**。

### 节气

月柱分界依赖节气。脚本采用 21 世纪节气速算公式，误差 ±1 日。

**限制**：交节前后一日、真太阳时校正、晚子时（23:00 后属次日还是当日子时）换日，本 Skill 不做处理，输出已标注需人工核对。精密命理排盘请用专业历法库。

## 七、实战示例

```bash
python scripts/yijing.py ganzhi --date 2026-09-22 --hour 午
python scripts/yijing.py ganzhi --year 2026
```

输出年柱、月柱、日柱、时柱与年柱纳音，并附限制提示。
