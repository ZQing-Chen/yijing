# 子平八字：排盘、十神、大运、神煞、格局、用神

采用**子平法通论**。凡遇流派分歧处，本文明确写出本引擎的取法与口径，不冒充唯一正解。

## 一、排四柱

| 柱 | 分界 | 说明 |
|---|---|---|
| 年柱 | 立春 | 立春前出生算上一年，与农历正月初一不是一回事 |
| 月柱 | 十二「节」 | 立春、惊蛰、清明、立夏、芒种、小暑、立秋、白露、寒露、立冬、大雪、小寒 |
| 日柱 | 夜半子正 | 公式精确值，本引擎最可靠的一项 |
| 时柱 | 两小时一辰 | 23:00-01:00 为子时；日干定起时干 |

月干由年干起月：**甲己之年丙作首，乙庚之岁戊为头，丙辛必定寻庚起，丁壬壬位顺行流，戊癸何方发，甲寅之上好追求**。
时干由日干起时：**甲己还加甲，乙庚丙作初，丙辛从戊起，丁壬庚子居，戊癸何方发，壬子是真途**。

> **Gotcha**：月柱用「节」不用「气」。雨水、春分这类「气」只用于纪月名，不用于换月柱。

## 二、十神

以日主天干为我，按五行生克加**阴阳同异**取十神：

| 关系 | 阴阳同 | 阴阳异 |
|---|---|---|
| 同我 | 比肩 | 劫财 |
| 我生 | 食神 | 伤官 |
| 我克 | 偏财 | 正财 |
| 克我 | 七杀（偏官） | 正官 |
| 生我 | 偏印（枭神） | 正印 |

例：日主乙（阴木），见庚（阳金）——金克木、阴阳异 → 正官；见辛（阴金）——克我、阴阳同 → 七杀。

地支取十神看**藏干**，本气／中气／余气各算一份，输出中一并列出。

## 三、日主强弱

三端打分，**权重为本引擎自定义**，非古籍定论，目的是让判定可逐条复核：

| 端 | 依据 | 分值 |
|---|---|---|
| 得令 | 月支同气 +30；生我 +20；我生 -10；克我 -20；我克 -10 |  |
| 得地 | 四支藏干中见日主同五行：本气 +12、中气 +8、余气 +4 |  |
| 得势 | 其余三天天干：同我／生我 +8；我生／我克／克我 -6 |  |

判定：≥ +25 偏强，≤ -10 偏弱，其间为中和。输出会列出**每一条加减依据**，便于人工复核或改权重。

> **Gotcha**：得地只看四柱地支藏干是否含日主五行，不因「日主坐支被冲」而扣减——冲合对强弱的影响属进阶判断，本引擎不处理。

## 四、大运

**顺逆**：年干阳、男命 → 顺行；年干阳、女命 → 逆行；年干阴、男命 → 逆行；年干阴、女命 → 顺行。即「阳男阴女顺，阴男阳女逆」。

**起运**：自出生日起，顺行数到**下一个节**，逆行数到**上一个节**，得天数；**三日折一岁、一日折四月**。

例：1990-05-20 生，庚午年（庚为阳干）男命 → 顺行，下一个节是芒种（约 06-05），距 16 天 → 5 岁 4 个月起运。

**大运干支**：自月柱干支顺（逆）行一位起，每步十年，共排八步。

**小运**（起运前）：男命一岁起丙寅顺行，女命一岁起壬申逆行。

> **Gotcha 1**：起运用「节」不用「气」，用错会整个大运序列偏移。
> **Gotcha 2**：节气用 21 世纪速算公式，误差 ±1 日，起运岁数相应约 ±0.4 岁偏差，交节当日出生必须人工核对。

## 五、神煞

内置 21 组按柱查的神煞（天乙、文昌、太极、天德、月德、禄神、羊刃、驿马、桃花、华盖、将星、劫煞、亡神、孤辰、寡宿、红鸾、天喜、红艳、金舆、国印、天医）＋日柱魁罡／日贵＋日柱旬空。

**取用口径**：驿马、桃花、华盖、将星、劫煞、亡神、孤辰、寡宿、红鸾、天喜以**年支**取；天乙、文昌、太极、禄神、羊刃、红艳、金舆、国印以**日干**取；天德、月德、天医以**月支**取。

> **Gotcha**：神煞只作辅助参考，**不得单独断吉凶**。古诀有「神煞不如格局，格局不如用神」之说，本引擎输出神煞后必附此定位。

## 六、格局

月令透干取格：

1. 月支藏干（本气→中气→余气）依次看是否透出到年、月、时三天干；
2. 先透者定格；
3. 皆不透，取月令本气十神定格。

八格：正官、七杀、正财、偏财、正印、偏印、食神、伤官。
月令本气为比劫时**不属八格**，通论作建禄／月刃论，用神另寻财官食伤。

## 七、用神

三条线索并列给出，不做单一裁决：

| 线索 | 取法 |
|---|---|
| 扶抑（主） | 日主偏强宜克泄耗（官杀、食伤、财）；偏弱宜生扶（印、比劫）；中和扶抑皆轻 |
| 调候（参考） | 按出生月支的寒暖燥湿取喜忌，本引擎用**简化季节通论**，非《穷通宝鉴》逐日取用 |
| 通关（参考） | 两行皆旺而相战时，取「我所生、又能生对方」的那一行通关 |

> **Gotcha**：用神是八字体系里流派分歧最大的一环（扶抑、调候、格局、病药各派取法不同）。本引擎按扶抑通论给结论，并明确标注非唯一结论，遇到争议不强行裁定。

## 八、流年

指定 `--liunian` 时给出该年干支、相对日主的十神，以及与四柱地支构成的冲、合、刑、害、破（含辰午酉亥自刑）。

## 九、精度边界（每次输出必提示）

- 节气速算误差 ±1 日 → 年柱、月柱在交节前后一日需人工核对；起运岁数约 ±0.4 岁偏差
- **不做真太阳时换算**：`--city` 只给出与北京时间的分钟差提示，不改盘；新疆、西藏等地实际时差可达 1-2 小时，可能整体错一个时辰
- 晚子时（23:00-24:00）换日规则未含
- 日柱为精确值，可放心使用
- 不含：十神坐支旺衰、刑冲合会的量化增减、纳音批命、神煞权重打分、大运与流年的吉凶断语

## 十、绝不做什么

- 不混用盲派、新派、纳音批命等其他体系口诀
- 不定论吉凶，不预测具体事件、日期、数字
- 不用于医疗、法律、金融投资、生育、人身安全的决策依据
- 不因神煞在而断吉、神煞不在而断凶
- 数据不出本地，出生信息不落盘
