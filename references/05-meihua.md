# 梅花易数：起卦与体用

## 一、先天卦数

起卦一律用**先天八卦数**：

乾一、兑二、离三、震四、巽五、坎六、艮七、坤八。

除 8 取余，余 1 得乾……余 7 得艮，**整除（余 0）为 8，得坤**。

## 二、起卦法

### 数字起卦

任意两个数（报数、门牌、字数皆可）：

- 上卦 = 第一个数 mod 8
- 下卦 = 第二个数 mod 8
- 动爻 = （两数之和）mod 6，余 0 为 6

```bash
python scripts/yijing.py cast-time --numbers 12 8
```

三数时可第三数直接定动爻。

### 时间起卦

- 上卦 = （年支序号 + 农历月 + 农历日）mod 8
- 下卦 = （年支序号 + 农历月 + 农历日 + 时支序号）mod 8
- 动爻 = （年支序号 + 农历月 + 农历日 + 时支序号）mod 6

地支序号：子 1、丑 2、寅 3、卯 4、辰 5、巳 6、午 7、未 8、申 9、酉 10、戌 11、亥 12。

```bash
python scripts/yijing.py cast-time --lunar 7 8 12 6
```

**限制**：本 Skill **不内置公历转农历**。时间起卦需你自行提供农历年月日与时支，避免换算出错。

### 其他起卦法（本 Skill 未实现，按此规则可自行换算）

声音起卦：闻声几响，以声数起上卦，加时辰数起下卦。
字数起卦：一字者左右分上下卦，两字者各为一卦，多字者平分。
物数起卦：所见物之数目起卦，加时辰定动爻。

## 三、体用与互变

- **体卦**：下卦，代表问卦者自身。
- **用卦**：上卦，代表所问之事或对方。
- **互卦**：由本卦二三四爻组成下互卦、三四五爻组成上互卦，表示事情中间过程。
- **变卦**：动爻阴阳互变后之卦，表示结局。

### 体用吉凶

| 体用关系 | 判断 |
|---|---|
| 用生体 | 吉，有外助 |
| 体克用 | 吉，费力可成 |
| 体用比和 | 吉，同类相助 |
| 体生用 | 耗，损己利人 |
| 用克体 | 凶，受阻受压 |

**易错点**：体用关系只看**五行生克**，不看卦名吉凶。一个卦名带「凶」字，仍可能体用关系为吉。

**易错点**：体用是梅花易数的概念，**不要与六爻的世应混用**。同一卦用梅花断和用六爻断是两套体系，结论不可互相印证。

## 四、断卦次序

1. 取本卦卦辞为事情本体。
2. 看体用五行关系定吉凶大势。
3. 看互卦定中间过程。
4. 看变卦定结局。
5. 取动爻爻辞为关键提示。
6. 结合卦象类象推断人物、方位、时间。

## 五、金钱卦（另一套起卦法）

金钱卦用三枚铜钱，每爻摇一次，共六次：

| 结果 | 数值 | 爻性 |
|---|---|---|
| 三背 | 9 | 老阳（阳，动爻） |
| 二背一字 | 8 | 少阴（阴，不变） |
| 一背二字 | 7 | 少阳（阳，不变） |
| 三字 | 6 | 老阴（阴，动爻） |

即：背计 3、字计 2，三枚之和即爻值。老阴（6）、老阳（9）为动爻，阳极变阴、阴极变阳。

```bash
python scripts/yijing.py cast-coin --backs 3 2 2 1 0 3   # 每爻背面个数，初→上
python scripts/yijing.py cast-coin 9 8 8 7 6 9           # 直接给爻值，初→上
python scripts/yijing.py cast-coin --random
```

**易错点**：六次结果**自初爻向上爻**依次记录，顺序颠倒则卦完全不同。

**易错点**：「字」「背」的阴阳定义各流派相反。本 Skill 采用通行约定：背面（有字的一面按流派不同，此处以「背」计 3）多者为阳。若你的师门相反，请改用直接输入爻值的方式。

**断法**：六爻皆静取本卦卦辞；有动爻则取动爻爻辞，并参考变卦。

### 用硬币替代铜钱

没有铜钱时，**用三枚硬币摇六次**，与铜钱法完全等价：

| 每次背面个数 | 数值 | 爻性 |
|---|---|---|
| 0 个背 | 6 | 老阴（阴，动爻） |
| 1 个背 | 7 | 少阳（阳，不变） |
| 2 个背 | 8 | 少阴（阴，不变） |
| 3 个背 | 9 | 老阳（阳，动爻） |

硬币最好同规格、同年份三枚，避免大小重量差异带来手感偏差。

**关键：必须是「三枚摇六次」，不能「六枚摇一次」。** 六枚一次摇、数背面总数，无论怎么映射到 6/7/8/9，都凑不出铜钱法规定的 1/8、3/8 概率结构（老阴老阳各 1/8，少阴少阳各 3/8，动爻率 1/4）。结果是动爻概率掉到约 3%，卦几乎不变，变卦失去意义。

实在没有硬币，用 `--random` 让脚本随机生成六爻，数学上等价于一次摇卦：

```bash
python scripts/yijing.py cast-coin --random
```

### 「正／反」记数口径的换算

用户常以「正记 3、反记 2，三数之和定爻性」描述掷币结果。该口径与本 Skill 的「背面个数」**完全等价**，把「正」视作「背」计数即可：

| 掷币结果 | 三数之和 | 等价于背面个数 | 爻值 |
|---|---|---|---|
| 正正正 | 9 | 3 | 老阳（动） |
| 正正反 | 8 | 2 | 少阴 |
| 正反反 | 7 | 1 | 少阳 |
| 反反反 | 6 | 0 | 老阴（动） |

**换算不改变任何结果**，无需改动接口，直接把「正面个数」当 `--backs` 传入：

```bash
python scripts/yijing.py cast-coin --backs 2 0 2 1 2 2   # 六次「正」的个数
```

**注意**：若用户采用相反约定（反记 3、正记 2），则「背面个数 = 3 − 正面个数」，需先转换再传入。遇到用户的记数约定与本表不一致时，先确认是哪一面记为 3，再换算，不要默认。

### 静卦（六爻无动爻）如何取用

六次摇出全是少阳（7）或少阴（8），没有老阴（6）、老阳（9），即为**六爻安静，不变卦**。取用法：

1. **以本卦卦辞断吉凶主体**，不看变卦（无变卦可看）。
2. **兼看世应六亲与卦象大象**（六爻路径），或看体用关系（梅花路径）——两条路径仍不混用。
3. **不取某一爻的爻辞作为结局指向**。无动爻即无「事之发动处」，强行挑一爻作断属于附会。
4. 可参考**卦主之爻**（如复卦初九「一阳来复」为成卦之主）作为补充提示，但不作定论。
5. 静卦主**事情维持原状、宜守不宜进**；卦辞中若有「利有攸往」类字样，仍可行动，但过程少变动。

## 六、结果使用边界

起卦与断卦属传统文化中的象征性推演，用于启发思考、提供另一种视角。**不用于医疗、法律、金融投资、生育、人身安全等重大现实决策**。涉及这些领域请以专业意见为准。
