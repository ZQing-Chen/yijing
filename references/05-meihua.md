# 梅花易数：起卦与体用

## 一、先天卦数

起卦一律用**先天八卦数**：

乾一、兑二、离三、震四、巽五、坎六、艮七、坤八。

除 8 取余，余 1 得乾……余 7 得艮，**整除（余 0）为 8，得坤**。

## 二、起卦法

### 数字起卦

任意两个数（报数、门牌、字数皆可）：

- 上卦 = 第一个数 mod 8
- 下卦 = 第二个数 mod 8
- 动爻 = （两数之和）mod 6，余 0 为 6

```bash
python scripts/yijing.py cast-time --numbers 12 8
```

三数时可第三数直接定动爻。

### 时间起卦

- 上卦 = （年支序号 + 农历月 + 农历日）mod 8
- 下卦 = （年支序号 + 农历月 + 农历日 + 时支序号）mod 8
- 动爻 = （年支序号 + 农历月 + 农历日 + 时支序号）mod 6

地支序号：子 1、丑 2、寅 3、卯 4、辰 5、巳 6、午 7、未 8、申 9、酉 10、戌 11、亥 12。

```bash
python scripts/yijing.py cast-time --lunar 7 8 12 6
```

**限制**：本 Skill **不内置公历转农历**。时间起卦需你自行提供农历年月日与时支，避免换算出错。

### 其他起卦法（本 Skill 未实现，按此规则可自行换算）

声音起卦：闻声几响，以声数起上卦，加时辰数起下卦。
字数起卦：一字者左右分上下卦，两字者各为一卦，多字者平分。
物数起卦：所见物之数目起卦，加时辰定动爻。

## 三、体用与互变

- **体卦**：下卦，代表问卦者自身。
- **用卦**：上卦，代表所问之事或对方。
- **互卦**：由本卦二三四爻组成下互卦、三四五爻组成上互卦，表示事情中间过程。
- **变卦**：动爻阴阳互变后之卦，表示结局。

### 体用吉凶

| 体用关系 | 判断 |
|---|---|
| 用生体 | 吉，有外助 |
| 体克用 | 吉，费力可成 |
| 体用比和 | 吉，同类相助 |
| 体生用 | 耗，损己利人 |
| 用克体 | 凶，受阻受压 |

**易错点**：体用关系只看**五行生克**，不看卦名吉凶。一个卦名带「凶」字，仍可能体用关系为吉。

**易错点**：体用是梅花易数的概念，**不要与六爻的世应混用**。同一卦用梅花断和用六爻断是两套体系，结论不可互相印证。

## 四、断卦次序

1. 取本卦卦辞为事情本体。
2. 看体用五行关系定吉凶大势。
3. 看互卦定中间过程。
4. 看变卦定结局。
5. 取动爻爻辞为关键提示。
6. 结合卦象类象推断人物、方位、时间。

## 五、金钱卦（另一套起卦法）

金钱卦用三枚铜钱，每爻摇一次，共六次：

| 结果 | 数值 | 爻性 |
|---|---|---|
| 三背 | 9 | 老阳（阳，动爻） |
| 二背一字 | 8 | 少阴（阴，不变） |
| 一背二字 | 7 | 少阳（阳，不变） |
| 三字 | 6 | 老阴（阴，动爻） |

即：背计 3、字计 2，三枚之和即爻值。老阴（6）、老阳（9）为动爻，阳极变阴、阴极变阳。

```bash
python scripts/yijing.py cast-coin --backs 3 2 2 1 0 3   # 每爻背面个数，初→上
python scripts/yijing.py cast-coin 9 8 8 7 6 9           # 直接给爻值，初→上
python scripts/yijing.py cast-coin --random
```

**易错点**：六次结果**自初爻向上爻**依次记录，顺序颠倒则卦完全不同。

**易错点**：「字」「背」的阴阳定义各流派相反。本 Skill 采用通行约定：背面（有字的一面按流派不同，此处以「背」计 3）多者为阳。若你的师门相反，请改用直接输入爻值的方式。

**断法**：六爻皆静取本卦卦辞；有动爻则取动爻爻辞，并参考变卦。

## 六、结果使用边界

起卦与断卦属传统文化中的象征性推演，用于启发思考、提供另一种视角。**不用于医疗、法律、金融投资、生育、人身安全等重大现实决策**。涉及这些领域请以专业意见为准。
