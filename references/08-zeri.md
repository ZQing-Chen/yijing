# 择日：通书宜忌与吉神凶煞

## 一、数据来源与可信度

宜忌、吉神、凶煞、农历日期、日柱干支、十二时辰宜忌，全部来自**随包分发的内置历法库 lunar-python**（6tail，MIT 协议），位于 `assets/vendor/lunar_python/`。

**这一条必须如实告知用户**：本 Skill 自身不生产择日数据，宜忌表是引用第三方历法库的通书通例，不是本 Skill 的独创结论，也不是模型凭记忆编造的。若用户追问数据来源，照实说明。

该库为纯 Python 实现，只做本地计算，不联网、不写文件、不需要安装任何依赖。

## 二、指令

```bash
python scripts/yijing.py zeri --start 2027-01-01 --end 2027-12-31 --purpose 嫁娶 \
        --shengxiao 牛,鼠 --avoid-zhi 酉,寅 --weekday workday --top 5

python scripts/yijing.py zeri --date 2028-01-01 --days 366 --purpose 嫁娶 \
        --prefer-zhi 亥,子 --weekday weekend
```

| 参数 | 说明 |
|---|---|
| `--date` + `--days` | 起始日期 + 天数（默认 90），简写形式 |
| `--start` + `--end` | 起止日期，`--end` 省略时为起始后 90 天 |
| `--purpose` | 事项，逗号分隔，默认 `嫁娶`。命中「宜」中任一项即入选 |
| `--shengxiao` | 避冲生肖，逗号分隔，如 `--shengxiao 牛,鼠` |
| `--avoid-zhi` | 避冲地支（通常填当事双方的日支），如 `--avoid-zhi 酉,寅`，软性降权 |
| `--prefer-zhi` | 偏好地支（通常填用神当令之支），如 `--prefer-zhi 亥,子`，加分 |
| `--weekday` | `any` / `workday`（周一至周五）/ `weekend`（周六日） |
| `--top` | 输出条数，默认 8 |

区间上限 3660 天。日期非 `YYYY-MM-DD` 或区间倒置时退出码 2 并给中文提示。

## 三、筛选规则

### 硬排除（命中即剔除，不参与评分）

| 规则 | 判定 |
|---|---|
| 三娘煞 | 农历初三、初七、十三、十八、廿二、廿七 |
| 杨公忌 | 正月十三、二月十一、三月初九、四月初七、五月初五、六月初三、七月初一、七月廿九、八月廿七、九月廿五、十月廿三、冬月廿一、腊月十九 |
| 月破 | 日支与月支相冲 |
| 岁破 | 日支与年支相冲 |
| 冲生肖 | 当日冲煞生肖命中 `--shengxiao` |
| 忌中含事项 | 该事项出现在当日「忌」中 |

### 软性调整

- 日支命中 `--avoid-zhi`：−3
- 日支命中 `--prefer-zhi`：+4

### 评分权重（全部列出，可复核、可改）

| 类别 | 分值 |
|---|---|
| 宜中每命中一个指定事项 | +4 |
| 天德、月德 | +8 |
| 天德合、月德合、天喜、天赦、不将 | +4 |
| 三合、六合、母仓、五富、五合、临日、福生、生气、续世、天后、时阳、时德、民日、四相、阳德、阴德、天仓、金堂、敬安、普护、解神、益后、青龙、明堂、金匮、玉堂、司命、宝光、鸣吠、鸣吠对 | +1 |
| 每个凶煞 | −2 |

**为什么天德月德权重最高**：传统择日通例认为德神可解部分凶煞，故优先级高于吉神数量。这会让「天德＋月德双值之日」通常排在只有一堆次级吉神的日子之前——即便前者凶煞条目更多。这是按通例设定的取向，不是唯一标准；若用户更看重「凶煞越少越好」，应把表中凶煞列一并提出，由用户自行权衡。

### 吉时

输出「宜」中含指定事项、且未标「诸事不宜」的时辰。同时标注该日上午（辰、巳、午）是否有吉时。

## 四、常见事项名

嫁娶、纳采、订盟、移徙、入宅、开市、出行、动土、安葬、祈福、求嗣、祭祀、斋醮、开光、立券、交易、纳财、修造、破土、安床。

**领证与婚礼要分开查**：登记领证对应「纳采、订盟」，婚礼宴席对应「嫁娶」。两者在通书中是不同事项，宜忌不同，不要混用。

## 五、易错点

- **宜忌不等于八字合婚**。本指令只做通书层面的日课筛选，**不看当事人生辰、不看合婚、不看格局用神**。要综合八字，必须先跑 `bazi` 得到双方喜用五行，再用 `--prefer-zhi` 把用神当令的地支传进来——两步是分开的，本指令不会自动替你合。
- **时辰要换算成北京时间**。表中时辰是传统地支时辰，按地方真太阳时计。重庆（东经约 106°）比北京时间晚约 56 分钟，再叠加当日均时差，实际到场一般顺延 40–70 分钟。
- **法定节假日以官方公布为准**。国务院通常在前一年 11 月公布次年放假安排，`--weekday workday` 只按周一至周五判断，遇节假日须另行核对。
- **地方民俗差异**。三娘煞、杨公忌属流传较广的民间通例，各地取舍不一，本指令默认全部剔除。

## 六、不做什么

- 不做八字合婚、不判格局喜忌、不算双方八字冲合——这些在 `bazi` 指令，两者不互相替代。
- 不断吉凶、不预测事情结果。
- 不提供财神方、喜神方等方位数据（库中有方位字段但本指令未取用，**不要凭印象编方位**）。
- 不声称「此日必成」「此日必有喜」。
