# 调用契约与输出格式

## 一、统一约定

**调用形式**

```bash
python scripts/yijing.py <指令> [参数] [选项]
```

工作目录为 Skill 根目录。脚本只读 `assets/data/` 下的 JSON，不写文件、不联网、不读取用户个人数据。

**输出格式（全部指令一致）**

1. 标题行：`## <内容>`
2. 结论行：加粗的关键结论
3. 结构化表格：Markdown 表
4. 原文出处：卦名 + 爻位，便于回查原文
5. 限制提示：以 `【提示】` 开头的边界说明

**退出码**

| 码 | 含义 |
|---|---|
| 0 | 成功 |
| 2 | 参数错误、查不到目标或数据文件缺失 |

**错误处理**：错误信息以 `【错误】` 单行输出并给出可执行补救（如提示用 `list` 查全部卦名），不抛 Python 栈。

## 二、指令一览

| 指令 | 参数 | 说明 |
|---|---|---|
| `list` | 无 | 输出 64 卦总表（序号、卦名、全称、上下卦、宫、宫序） |
| `gua` | 卦名 / 全称 / 拼音 / 1-64 序号 | 卦画、卦辞、彖传、象传、爻辞表、八宫归属 |
| `cast-coin` | 6 个爻值 6/7/8/9，或 `--backs` 6 个 0-3，或 `--random` | 金钱卦起卦，本卦、变卦、动爻、动爻爻辞 |
| `cast-time` | `--numbers` 2-3 个数，或 `--lunar` 年支 月 日 时支 | 梅花易数起卦，本卦、互卦、变卦、动爻、体用 |
| `najia` | 卦名 / 序号 | 八宫、世应、纳甲干支、爻五行、六亲 |
| `ganzhi` | `--date` YYYY-MM-DD / `--year` 年 / `--hour` 时辰 | 四柱干支与年柱纳音 |
| `wuxing` | 1 或 2 个五行 | 生克关系、方位季节干支 |
| `xiang` | 八卦名或卦名 | 八卦类象全表，或重卦上下卦类象对照 |
| `relation` | 1-3 个地支或天干 | 冲合刑害破、五合 |
| `bazi` | `--date` YYYY-MM-DD、`--hour` 时辰或 0-23、`--gender` 男/女，可选 `--city`、`--liunian` | 四柱、十神、强弱打分、大运小运、神煞、格局、用神、流年 |
| `env` | 无 | 环境自检，输出 ready / needs_setup |

## 四、数据文件

| 文件 | 内容 | 加载方式 |
|---|---|---|
| `assets/data/base.json` | 八卦、八宫纳甲、五行、干支关系 | 脚本运行时读取 |
| `assets/data/gua64.json` | 64 卦卦辞、彖传、象传、386 爻辞 | 脚本按需读取，不进对话上下文 |
| `assets/data/ganzhi.json` | 六十甲子、纳音、藏干、十二长生 | 脚本运行时读取 |
| `assets/data/bazi.json` | 十神规则、神煞表、强弱权重、调候、用神、城市经度 | 脚本运行时读取 |

**不要**把 `gua64.json` 整体读入对话。386 爻辞全量约数万字，只用脚本按需提取。需要大范围比对时再分段读取。
